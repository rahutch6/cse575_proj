## Overview
This repository contains an implementation of Style Transfer using CNNs as a project for CSE575 at Arizona State University. 

## Installation
1. Clone the repository:
    ```bash
    git clone git@github.com:rahutch6/cse575_proj.git
    ```
2. Navigate to the project directory:
    ```bash
    cd cse575_proj
    ```

## Usage
1. Run the main script:
    ```bash
    python run_style_transfer.py
    ```
2. Use the -h flag for a list of available configurations
